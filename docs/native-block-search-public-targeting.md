# Owned public targeting for the existing E03 gate

The a96 hosted public-control proof established real scope Pressed transitions,
focus-away/back, exact physical query readback and zero PTY input under the same
foreground collector. This fixture-only successor applies that targeting route
to the existing raw and snapshot scenarios. It is not native search acceptance.

Each scenario retains a separate fresh HOME/app and now starts an isolated private
session/accessibility bus using the same explicit environment allowlist. Generated
E03 emitter paths are added explicitly. No host display, bus, accessibility settings,
clipboard or credentials are reused. The fixture uses system python3-dbus.

The opening chord remains one Ctrl+Shift+G. The named PID-owned Block Search frame,
editable Entry and scope controls must be unique, related and visibly bounded.
A fresh expected prior query is required (empty on the first open, then the last
verified process-lifetime intent). Query readiness requires observed focus. If
already focused, that state is recorded without invoking or claiming a transition.
If a known scope has focus, one public GrabFocus must return focus to the editor
while preserving scope intent and all target identities.

Physical Ctrl+A/type/copy remains the query-input path. The exact bytes copied from
the isolated fixture clipboard are now persisted, with SHA-256, expected query,
public editor Text, editor path and the matching tree filename. Wrong bytes are
also retained before failing. Query OCR and relative Latest/Out geometry are no
longer prerequisites or sources of query/scope coordinates.

Out targeting either records a uniquely already-pressed Out state without dispatch,
or requires a fresh opposing All/Cmd state, one public click and an observed Out
Pressed response on the identical controls. No no-op is claimed as a transition.

Search this retained output, Stop search, Restart this output and Earlier history
remain the only permitted semantic operation names. The existing visible OCR
precondition still runs; the target is then resolved freshly by exact name,
PushButton role, public action name/index, same picker ancestry and current bounds.
One public action is issued. A true response is recorded as pending the existing
search oracle; it is never itself successful search evidence. There is no Latest
fallback, cached rectangle, repeated action or private controller mutation.

Raw/snapshot input size/digest/PTY identity, 100k rows, 64 retained snapshots,
active-Stop plus retained-row claim, loading Return, explicit Stop, claim identity,
Restart/Complete, pointer result activation, final neighboring output-row navigation,
RSS sampling, polling timeouts and workflow 12-minute limit are unchanged. Result
and coverage OCR stays strict. New evidence may reveal further fixture limitations;
this patch does not relax those oracles or certify any performance metric.

The public-control probe and its zero-byte PTY test remain separate. The actual
search gate must let its real synthetic emitters run normally. No production files
are changed. Activated-service exit remains explicitly unverified; existing Smoke
cleanup is always attempted even when group signaling fails.
